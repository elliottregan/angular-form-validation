The Resource API provides reactive data fetching with signals:

// Define a signal for the parameter
userId = signal(1);

// httpResource automatically tracks signal dependencies
userResource = httpResource<User>(() => ({
  url: `https://api.example.com/users/${this.userId()}`,
  method: 'GET',
}));

// Access data reactively in templates
@if (userResource.isLoading()) {
  <p>Loading...</p>
} @else if (userResource.hasValue()) {
  <p>{{ userResource.value()?.name }}</p>
}

When userId() changes, the resource automatically refetches the data!
